# WorthChex

Free UK money calculators and guides, served as a static site on GitHub Pages at https://worthchex.com.

## Structure

- `*-calculator/index.html`: one folder per calculator. Each page loads its engine plus `reset-fixes.js` and `site.js`.
- `financial-suite-v4.js`: tax, take-home pay, property tax (SDLT, LBTT, LTT), VAT, compound growth and car finance engine.
- `calculator-suite-final.js`: affordability, savings, debt payoff, mortgage and personal loan engine and page logic.
- `money-guides/`: guide articles. `calculators/`, `about/`, `methodology/`, `privacy/`: hub and information pages.
- `style.css` (+ `style-core.css`), `calculator-v2.css`, `content-enhancements.css`, `home.css`: styles. `site.css` and `site.js`: shared header, mobile menu and footer.

## Shared header, footer and head tags

The header, footer, Open Graph tags, structured data and stylesheet links are generated by:

```
python3 tools/apply-layout.py
```

Edit the template in that script, then run it. It is safe to run repeatedly.

## Tests

```
node tests/site-audit.test.js
node tests/accuracy.test.js
node tests/calculator-suite.test.js
node tests/new-tools-regression.test.js
node tests/reset-fixes.test.js

```

`tests/accuracy.test.js` holds hand-checked answers for the 2026/27 tax year. Update it alongside any rate change (Income Tax, National Insurance and student loans each April; property taxes when announced).
